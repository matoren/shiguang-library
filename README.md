# 一不小心就记住了

收藏喜欢的作品，记录真实的评价。

版本 2.1.0。书籍、电影/剧集和游戏的个人收藏、评分、封面与简评应用。安卓优先，PWA，本地保存，无应用账号、云端数据库或自动同步。

## 打开应用

正式网址：**https://matoren.github.io/shiguang-library/**

安卓 Chrome 打开后等待离线缓存就绪，从菜单选择“安装应用”或“添加到主屏幕”。首次访问需要网络。已有安装可以在“我的 → 设置与数据 → 检查应用更新”确认更新后重新打开；旧界面入口为“设置 → 检查应用更新”。不要通过清除网站数据或卸载来更新。

Windows 本地预览：双击 `start.cmd`，保持窗口开启，再打开 http://127.0.0.1:4173/library/ 。此地址和正式网址属于不同存储来源；迁移时应先备份再恢复。

## 使用

- 五个导航入口：首页、书籍、电影、游戏、我的。排行榜在“我的”页首屏，也可从首页高分精选直接进入。
- 首页按添加时间展示最近收藏，按已完成作品的最终评分展示高分精选，两者均为横向封面列表。三个概览分别显示收藏总量与已完成有效评分的平均分。
- 添加作品时可手动填写，也可点击“联网搜索作品”，核对候选后填入。不会自动保存，不覆盖评分、评论、状态或完成日期；替换已填写信息前会确认。
- 书籍使用五类权重及六维评分。没有出版年份输入、展示或筛选；旧记录的年份仍在内部保留，搜索中参考年份不会写入记录。
- 电影和游戏支持四维标准评分及快速评分。游戏可选“剧情不适用”，其余权重自动归一化。游戏不显示平台或时长，旧兼容字段仍保留。
- 各维度以 0.5 分为步进，最终手动分和快速分以 0.1 为步进。未评分与 0 分严格区分。低于 7.0 显示 ✳，7.0 不标记。
- 搜索、筛选、六种排序、网格/列表、三类排行榜、自定义书籍权重和完成日期统计继续可用。只有已读、已看、已通关或已完成且有有效分数的作品参与排行榜及平均分。

## 联网搜索与图片

默认使用无需密钥的 Wikidata，支持中文作品名称、作者/导演/开发商、电影/游戏年份、类型等公开资料。图书可切换 Open Library 查找版本，但可用性取决于网络和服务状态。

只在主动搜索时发送输入的搜索词，不发送收藏列表、评分或评论。不依赖付费服务，也没有把私密 API 密钥写进前端。

封面若可合法获取，会下载、压缩并保存为本地图片数据，同时保留来源、作者和许可信息。Wikimedia Commons 图片仅在许可明确时处理；历史插图或参考图不保证是你所选版本的封面。电影和游戏的部分作品没有可用海报/封面，此时保留手动上传，下载失败也不会移除已有封面。书籍国家/地区不根据作者国籍或出版地猜测填入。

网络错误、限流或无结果时可继续手动添加。所有已经保存的记录和图片仍可离线查看。

## 备份和恢复

“我的 → 设置与数据 → 导出完整备份”会下载一个 JSON，包含三类记录、全部评分、权重快照、评论、日期、标签、完整图片、来源许可、设置和数据版本。

导入支持：

- **合并导入**：按 ID 和作品特征检测重复，提示后跳过，不静默覆盖。书籍重复识别不再依赖隐藏的出版年份。
- **覆盖恢复**：明确确认后用备份替换当前记录和设置，执行前建议先备份。

旧 v1 备份仍可导入。隐藏的年份、平台、时长及扩展字段会原样保留。导入先校验结构与图片，再以单次事务写入；错误或中断时回滚。逐张解码图片，减少恢复时内存占用。

请确认下载文件已保存，并定期另存安全位置。本地数据仍可能因清除网站数据、设备故障或卸载丢失，持久存储不能替代备份。

## 数据与升级原则

保持原网址、数据库名称 `private-media-library`、数据库版本 1、记录表和设置表，不通过重建数据库升级。启动应用只读现有数据，不重新计算评分。

每条作品保留原维度、权重、计算分、最终分、手动调整状态与规则版本。修改默认书籍权重仅影响新记录；应用旧记录需另行确认，并保留手动最终分。

旧版代码保留在 Git 历史提交 `e814415e556bc68c54551f2a3712e31ebf824e09`，并有本地升级前副本。发布使用新缓存版本和原有更新确认机制，只清理本应用旧静态缓存，不清理 IndexedDB。

保留旧网址及内部兼容标识是为了继续读取旧数据；用户界面、浏览器标题和 PWA 安装名称均为完整新名称。

## 验证与维护

无 npm 安装步骤。`npm start` 预览，`npm test` 运行全部核心与升级测试。目前 37 项通过。

独立临时数据库测试页（不修改收藏应用数据库）：

- `tests/browser.html`：11 项基础存储测试。
- `tests/upgrade-browser.html`：15 项升级兼容性测试。
- `tests/backup-file.html`：选择备份后验证独立恢复、图片解码和重开一致性。
- `tests/mobile.html`：320/360/412 像素手机布局检查。

GitHub Actions 自动执行语法与全部核心测试。安卓真机安装、软键盘、相册选择和系统回收后重开仍需用户验收；手机框架模拟不等同于真机。
